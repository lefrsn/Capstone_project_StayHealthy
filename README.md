# Stay Healthy - Medical Appointment Booking Website

Stay Healthy is a responsive web application that allows patients to book medical appointments, search for doctors by specialty, and leave reviews about their healthcare experience. The platform features user authentication with sign-up and login pages, an interactive appointment booking system with doctor search functionality, and a reviews section where patients can rate and provide feedback. Built with HTML, CSS, and JavaScript, it offers a clean, modern interface with smooth animations and real-time updates using npm and Live Server.

## Setup

```bash
npm install
npm start
```

Visit `http://127.0.0.1:8080` in your browser.
