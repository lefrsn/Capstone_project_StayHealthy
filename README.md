# Stay Healthy - Medical Appointment Booking Website

A modern, responsive web application for booking medical appointments, leaving reviews, and managing patient-doctor interactions.

## 🏥 Features

### 📱 **Pages Included**
- **Landing Page** - Beautiful hero section with call-to-action
- **Sign Up** - Patient registration with role selection
- **Log In** - Secure authentication page
- **Appointments** - Search and book appointments with doctors
- **Reviews** - View and submit reviews for doctors

### ✨ **Key Functionality**
- 🔐 User authentication (Sign Up/Log In)
- 🔍 Doctor search by specialty
- 📅 Appointment booking system
- ⭐ Star rating system for reviews
- 👁️ Password visibility toggle
- 📊 Reviews table with patient feedback
- 🎨 Responsive design for all devices
- 🚀 Live development server with real-time updates

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Icons**: Bootstrap Icons
- **Fonts**: Google Fonts (Lato)
- **Development Server**: Live Server (npm)
- **Package Manager**: npm

## 📋 Prerequisites

- Node.js and npm installed on your system
- A modern web browser

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/lefrsn/Capstone_project_StayHealthy.git
cd StayHealthy Inc
```

2. Install dependencies:
```bash
npm install
```

### Running the Project

Start the development server with live reload:
```bash
npm start
```

The website will open at `http://127.0.0.1:8080` with automatic refresh on file changes.
